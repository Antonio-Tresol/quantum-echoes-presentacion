# Quantum Echoes, presentacion

Diapositivas de la exposicion de Quantum Echoes (plataformero 2D con bucle
temporal), curso PF-1900, Universidad de Costa Rica.

Abrir la pagina publicada o el archivo `index.html` directamente.

Controles:

- Flechas izquierda y derecha, o clic en los bordes: cambiar de slide.
- Home / End: primera / ultima slide.
- L: laser pointer (Escape lo apaga).

Demo jugable: <https://tebansus.itch.io/quantum-echoes>
